# pg8000 is a pure-Python PostgreSQL driver. Pure-Python keeps synth offline
# (no manylinux wheel to pick) and removes the "which libc?" question that
# dogs psycopg2-binary on newer Lambda runtimes. It supports PostgreSQL
# scram-sha-256, TLS, and the long password value RDS IAM auth needs.
# boto3 is provided by the Lambda runtime and is NOT listed here.
